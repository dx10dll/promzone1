ПРОМЗОНА — версия {VER}

КАК ЗАПУСТИТЬ
1. Распакуйте архив в любую папку (не запускайте прямо из архива).
2. Запустите Promzona.exe.
3. Если Windows покажет «Система Windows защитила ваш компьютер» —
   нажмите «Подробнее» → «Выполнить в любом случае». Файл просто не подписан цифровой подписью.

Нужна Windows 10 или 11 (64 бит). Установка не нужна.

С ЧЕГО НАЧАТЬ
• При первом запуске откроется справка «Как играть» (потом — клавиша F1).
• Первый заказ уже принят: просто запустите время и посмотрите, как бригада точит втулки.
• Откройте «Заказы» внизу справа и примите ещё пару заказов.

УПРАВЛЕНИЕ
Камера ............................ WASD или стрелки, средняя кнопка мыши — перетаскивание
Масштаб ........................... колесо мыши
Выбрать человека/объект ........... левая кнопка мыши
Отменить инструмент/выделение ..... правая кнопка мыши или Esc
Пауза / скорость .................. Пробел / 1, 2, 3
Стройка / Объекты / Снос .......... B / O / X
Помещения / Электрика ............. R / E
Быстрое сохранение / загрузка ..... F5 / F9
Меню .............................. Esc

СОХРАНЕНИЯ И ЖУРНАЛ ОШИБОК
Сохранения:  %APPDATA%\Promzona\saves\
Журнал:      %APPDATA%\Promzona\logs\godot.log
(вставьте путь в адресную строку Проводника)

Если что-то сломалось — пришлите скриншот и файл godot.log.
